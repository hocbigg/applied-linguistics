# Projects: Applied Linguistics

These projects let you apply applied linguistics knowledge to produce tangible artifacts - corpus analyses, discourse studies, teaching materials, assessments, surveys, and policy documents. Each guide below is a practical walkthrough you can follow independently.

## Conduct a Corpus Analysis

- [Corpus Analysis with AntConc (Programming Historian)](https://programminghistorian.org/en/lessons/corpus-analysis-with-antconc)
- [Compiling a Corpus: From Texts to Analysis-Ready Data (LADAL)](https://ladal.edu.au/tutorials/corpus_compilation/corpus_compilation.html)
- [Corpus Analysis with Voyant Tools (Programming Historian)](https://programminghistorian.org/en/lessons/corpus-analysis-voyant-tools)
- [Corpus Linguistics with R (LADAL)](https://ladal.edu.au/tutorials/corpus_linguistics/corpus_linguistics.html)

## Write a Discourse or Textual Analysis

- [How to Use Critical Discourse Analysis for Policy Analysis (KM4D Journal)](https://www.km4djournal.org/99)
- [Discourse Analysis: Step-by-Step Guide with Examples (MAXQDA)](https://www.maxqda.com/blog-about-qualitative-and-quantitative-research/discourse-analysis-step-by-step)
